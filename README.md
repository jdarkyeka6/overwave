# OVERWAVE

A fast-start tower defense game built around skipping the slow opening and getting straight into upgrades, pressure and ridiculous late-game scaling.

## Current prototype

- Starts with four deployed towers and enough cash to build immediately
- 2× speed by default, with 1× / 2× / 4× controls
- Four tower classes: Pulse Cannon, Rail Blaster, Frost Node and Arc Coil
- Tower upgrades and selling
- Fast escalating enemy waves
- Runners, brutes, armored enemies and bosses
- Boss surge every 10 waves
- Endless scaling after wave 50
- Local best-wave saving
- Mouse, touch and keyboard controls
- Responsive layout for desktop and mobile

## Controls

- Click/tap a tower in the Arsenal, then click/tap open ground to deploy
- Click/tap an existing tower to upgrade or sell it
- `1` Pulse Cannon
- `2` Rail Blaster
- `3` Frost Node
- `4` Arc Coil
- `Space` pause

## Direction

OVERWAVE is designed around a much faster power curve than traditional tower defense games. The opening should feel like another game's midgame, while late waves become increasingly absurd.

The web build is deliberately dependency-light so it can be iterated quickly and later wrapped for the iOS App Store build.
